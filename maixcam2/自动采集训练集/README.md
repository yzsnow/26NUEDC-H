# MaixCAM2 自动训练集采集

这是独立采集应用，不加载识别模型，不初始化电机、UART、PID、连杆或比赛任务。

本工具只在 MaixCAM2 本地显示相机预览并按间隔保存训练图片，不提供赛题第 1 问所需的图传、
录像、接收或回放功能。比赛图传由外部 DJI Action 5 Pro 独立完成，与本工具及其他控制设备
没有电气连接。

## 使用

运行 `main.py` 后显示 `640x480` 实时画面。程序会读取
`/root/data/image/` 下所有 `project_数字` 格式的训练集文件夹，界面文字和按钮均为中文：

- `上一个`：停止采集时选择上一个训练集工程。
- `下一个`：停止采集时选择下一个训练集工程或新的工程编号。
- `开始`：3 秒后拍第一张，随后每隔 3 秒自动保存一张。
- `停止`：立即停止自动采集。
- `补光`：切换板载补光灯；切换后等待 500 ms 曝光稳定再保存。

采集中会锁定 `上一个` 和 `下一个`，必须先按 `停止` 才能切换工程。
启动时默认选择下一个新工程，避免误写已有数据。

训练图片在绘制界面前保存，所以不包含状态栏、文字或按钮。

## 保存规范

选择新的工程后按 `START` 才会创建目录，例如：

```text
/root/data/image/project_0001/
/root/data/image/project_0002/
```

图片使用 JPEG 质量 95，连续编号并记录补光状态：

```text
img_000001_light_off.jpg
img_000002_light_on.jpg
```

选择已有工程时，程序会扫描该目录内所有 `img_*.jpg`，从最大图片序号加一继续。
例如目录内最后一张是 `img_000127_light_off.jpg`，续采第一张就是
`img_000128_light_off.jpg` 或 `img_000128_light_on.jpg`，不会覆盖原图片。

保存失败时程序会停止自动采集，避免连续重复写入和刷屏报错。
