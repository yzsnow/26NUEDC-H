# 底盘惯性前馈串口协议

## 接口

- 小车端 `UART1_TX/PA8` 连接视觉主控串口 `RX`，两块主控必须共地。
- 电平为 MCU 的 TTL 串口电平，不要直接连接 RS-232 电平接口。
- 串口参数为 `115200, 8N1`，发送周期 `20ms`，即 `50Hz`。
- 小车端当前不处理控制命令；视觉主控可只接收，不需要回传。

## 帧格式

每帧固定 `32` 字节，小端序；有符号字段均为二进制补码 `int16_t`。

| 字节 | 字段 | 说明 |
|---|---|---|
| 0 | 帧头1 | 固定 `0xA5` |
| 1 | 帧头2 | 固定 `0x5A` |
| 2 | 协议版本 | 当前为 `0x01` |
| 3 | 数据长度 | 固定 `26`，对应字节4～29 |
| 4 | 序号 | 每帧加1，用于检查丢帧 |
| 5 | 任务号 | `2`=任务2，`4`=任务4，`56`=任务5/6 |
| 6 | 运动状态 | `0`=待机，`1`=运行，`2`=软停，`3`=停车后稳定 |
| 7 | 标志位 | bit0陀螺仪有效，bit1编码器有效，bit2任务4/5/6，bit3电机正在输出 |
| 8～9 | G356 X加速度 | `int16_t`，单位 `mg` |
| 10～11 | G356 Y加速度 | `int16_t`，单位 `mg` |
| 12～13 | G356 Z加速度 | `int16_t`，单位 `mg` |
| 14～15 | Roll | `int16_t`，单位 `0.01°` |
| 16～17 | Pitch | `int16_t`，单位 `0.01°` |
| 18～19 | Z轴角速度 | `int16_t`，单位 `0.01°/s` |
| 20～21 | 编码器纵向速度 | `int16_t`，单位 `mm/s` |
| 22～23 | 编码器纵向加速度 | `int16_t`，单位 `mm/s²` |
| 24～25 | 前进PWM | 左右轮平均值，单位 `0.1 PWM` |
| 26～27 | 转向PWM | `(右轮-左轮)/2`，单位 `0.1 PWM` |
| 28～29 | 前进PWM变化率 | 单位 `PWM/s`，可用于提前补偿 |
| 30～31 | CRC16 | CRC16-Modbus，低字节在前，覆盖字节0～29 |

## 视觉主控使用建议

1. 视觉位置 PID 继续作为低频主闭环，不要用加速度直接替代位置闭环。
2. 前后方向优先使用“前进PWM变化率”做提前前馈，再用编码器纵向加速度和 G356 前向轴做修正。
3. 圆弧横向惯性使用 G356 横向轴与 Z 轴角速度；G356 安装轴向由一次推车试验确认。
4. G356 加速度包含重力和安装倾角影响，可使用 Roll/Pitch去除静态分量，或在停车时自动记录三轴零偏。
5. 只有运动状态为 `1` 或 `2` 且标志位 bit2 为1时启用惯性前馈；状态变为 `3` 后应在约 `200～500ms` 内平滑撤销前馈。
6. 建议输出形式为 `视觉PID + K1×PWM变化率 + K2×编码器加速度 + K3×IMU加速度`，各增益从小到大逐步标定，并对前馈输出限幅。
